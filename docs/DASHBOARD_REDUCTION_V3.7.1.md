# Dashboard V3.7.1 — Reduction Pass

Objetivo: reducir ruido visual sin perder funcionalidad.

## Decisiones
- Se elimina la sidebar interna del Dashboard.
- `Métricas / Mapa de Sueños / Comunidad` es la única navegación interna.
- El background ornamental anterior se reemplaza por una atmósfera oscura mucho más silenciosa.
- Métricas se reduce a 4 señales protagonistas, 3 paneles principales y 3 insights.
- Mapa de Sueños reduce controles y prioriza imágenes/intenciones.
- Comunidad se reduce a hero, círculos, encuentros, personas y actividad reciente.
- Las interacciones locales existentes se conservan.
- Comunidad continúa siendo placeholder hasta identidad/backend real.

## Compatibilidad
- `/dashboard` continúa como ruta canónica.
- `/observatorio` continúa como alias.
- Hábitos, Semillas, Biblioteca, Chat, Hub, API y Tools permanecen sin cambios de producto.
