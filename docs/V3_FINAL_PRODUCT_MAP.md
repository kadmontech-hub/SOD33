# SØD V3.9999 — Mapa final de producto

## Tesis de arquitectura

La V3 final deja de tratar cada feature como un destino independiente. La navegación visible se reduce a necesidades humanas claras y conserva a SØD como núcleo transversal.

## Entrada / OUN

1. **Landing** (`/`)
2. **Acceso local** (`/identidad-local`)
3. **Calibración** (`/onboarding`)
4. **Hub** (`/hub`)
5. **Primera conversación** (`/experiencia` o overlay del Hub)
6. **Primera acción pequeña**
7. **Exploración del ecosistema**

La V3 no contiene formularios de contraseña. V4 reemplazará el acceso local por Auth real.

## Hub Central

### Núcleo SØD

- abre la conversación;
- conserva contexto de sesión local;
- tiene fullscreen opcional;
- historial persistente real queda para V4.

### Biblioteca

**Responsabilidad única:** conocimiento curado.

- Libros
- Videos

Eventos no viven aquí.

### Semillas

**Responsabilidad única:** significado + incorporación + colección personal.

- Presentación narrativa
- Mercado
- Tesoros
- Elementos operativo: Tierra / Agua / Viento / Fuego / Éter, 33 cada uno
- Animales: Próximamente
- Sodiaco: Próximamente

Mercado y Tesoros no ocupan navegación permanente: se accede desde el gateway omnipresente.

### Hábitos

**Responsabilidad única:** convertir intención en evidencia diaria.

- Tracker
- Rutina
- Metas

La información persiste localmente durante V3.

### Dashboard

**Responsabilidad única:** observar evolución.

- Métricas
- Mapa de Sueños
- Comunidad

Dashboard consume señales de otros mundos; no duplica su lógica.

### Comunidad

En V3 es un preview explícito, no una red social simulada.

- Telegram oficial
- evento / encuentro
- círculos futuros
- accesos oficiales a redes

Eventos pertenecen conceptualmente a Comunidad.

### Tools

No es un mundo del Hub.

- Ajustes
- Navegación
- Suscripción futura

## Loops de producto que V4 deberá conectar

### Loop de claridad

`Conversación → distinción → acción → evidencia → nueva conversación`

### Loop diario

`Entrar → Hábitos → marcar evidencia → Dashboard → observar continuidad`

### Loop de conocimiento

`Biblioteca → consumir → integrar → SØD / Dashboard`

### Loop de Semillas

`Comprender → explorar → incorporar → Tesoros → cultivar → integrar`

### Loop aspiracional

`Mapa de Sueños → intención → hábitos/metas → evidencia → actualización`
