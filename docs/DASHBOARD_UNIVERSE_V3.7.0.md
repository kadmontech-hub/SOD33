# Dashboard Universe V3.7.0

## Scope
V3.7.0 rebuilds `/dashboard` as three coordinated experiences without changing Hub, Habits, Seeds, Library or SØD Conversation.

### Metrics
- Reads local prototype signals from Habits, Seeds, Codes, Library progress and Events.
- Weekly consistency visualization, journey milestones, ecosystem pulse, insights and intention.
- Metrics are observational signals, not a score of personal value.

### Dream Map
- Cinematic aspirational board.
- Built-in inspiration cards plus user-created entries.
- URL and local upload support (prototype local persistence).
- Categories, progress, filters and removal.

### Community
- High-fidelity placeholder product surface for circles, encounters, paths and activity.
- RSVP/interested states persist locally.
- Identity, real people, messaging and social graph require V4/backend and are not claimed as live.

## Compatibility
- `/dashboard` remains canonical.
- `/observatorio` remains a compatibility alias.
- Existing state is extended through merge-safe defaults in `store.js`.
